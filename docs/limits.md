# Known limits (intentional for v1)

PitchPerfect is a portfolio project. Each limit below is on purpose, and each has a way forward.

| Limit                                                  | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Path forward                                                                                                                |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Legal pages are templates                              | Binding legal text needs a lawyer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Replace `/privacy` and `/terms` content before any real launch                                                              |
| One employer user per company                          | Teams need invites, roles, and ownership transfer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Add `companymembers` with roles and invite tokens                                                                           |
| Admin is a CLI, not a UI                               | Small operational surface                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Add an admin app behind SSO if moderation volume grows                                                                      |
| Voice depends on browser speech APIs                   | No paid speech service in v1; Firefox has no speech recognition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Add server-side STT/TTS behind the coach with streaming audio                                                               |
| No dark mode                                           | Keep one polished theme                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Add a dark token set; components already use tokens only                                                                    |
| English only                                           | Content, prompts, and rubric are English                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Localize lessons + prompts; add a `locale` to attempts                                                                      |
| US states only for student location                    | Demo audience is US-based                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Replace with country + region                                                                                               |
| No GDPR data export                                    | Not launching in the EU                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Add `GET /api/me/export` (JSON + résumé)                                                                                    |
| The daily token budget can be overshot                 | It is checked before a session starts; sessions already running finish their turns and scoring                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Reserve an estimated session cost when starting and refund unused tokens at the end                                         |
| Rate limits are counted in MongoDB                     | Fine for demo traffic: the counters are shared by every api instance, at the cost of a database write per counted request (only `/api/health` counts in memory, per instance)                                                                                                                                                                                                                                                                                                                                                                                                                                | Move the counters to Redis. The api config already accepts `REDIS_URL`, but no limiter reads it                             |
| No payments or subscriptions                           | Out of scope                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | —                                                                                                                           |
| No messaging between employers and students            | Email notifications cover interviews                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Add threaded messages with moderation                                                                                       |
| Users under 18 can't sign up                           | Protects minors' data and avoids consent flows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | School programs would need guardian/school consent flows                                                                    |
| Forgot-password is limited per email                   | 3 requests an hour per address stops reset-email floods, so someone who knows an address can use the limit up and delay that user's own reset for the rest of the hour. Accepted: the spec mandates the per-email limit and the reset link is the only thing delayed                                                                                                                                                                                                                                                                                                                                         | Add a second, per-IP limit and let a signed-in user change their password without the email flow                            |
| Sign-up attempts notify an existing address            | Signing up with a registered email answers `201` like a new account and emails the real owner, so repeated attempts (up to the 3/hour/IP limit) send that person repeated notices. Accepted: the spec mandates the no-enumeration answer and the notice                                                                                                                                                                                                                                                                                                                                                      | Rate-limit the notice per address (one an hour) independently of the sign-up limit                                          |
| Guard strikes need two checks                          | A rule hit alone, or with a live provider a model guard verdict the rules didn't share, redirects the turn without a strike, so ordinary sales lines never end a session. Accepted: an attacker whose wording slips past one of the two checks is still redirected every time, but can keep going until the 20-turn limit                                                                                                                                                                                                                                                                                    | Have the model guard return a confidence and count confident verdicts on their own                                          |
| Leak checks are rules, not understanding               | The canary and the hidden scenario are matched after canonicalisation, so a reply that translates or paraphrases a win condition, spells the canary with another language's letter names, uses a cipher such as ROT13, uses look-alikes outside the Cyrillic and Greek map, or gives less than half the canary in a reply (or spreads it over turns) gets through. A reply that says an objection with a look-alike or leetspeak inside it is regenerated once. Accepted: the canary has no meaning to translate, the persona never needs to quote a win condition, and the fixture covers the common tricks | Add a leak classifier to the moderator that is given the hidden scenario, and count canary pieces across a session's turns  |
| A flagged scenario falls back quietly                  | A planned scenario that fails the scenario check is replaced by a fixed persona for the skill and the job's title, without telling the student or the employer. Accepted: the student still gets a safe practice call; the coach logs `scenario_flagged`                                                                                                                                                                                                                                                                                                                                                     | Mark the job for review when its scenario falls back, and tell the employer what was removed                                |
| Joined emoji come apart in employer text and turns     | Invisible characters are stripped from job and company text and from student turns, including U+200D and variation selectors, so 👩‍💻 is saved as 👩💻, and the joiners Persian and some Indic scripts use for shaping are removed too. Accepted: the product is English-only and the joiners can hide text from a reader                                                                                                                                                                                                                                                                                      | Keep joiners between two emoji or two letters of a script that needs them                                                   |
| Automatic verification checks the domain, not the name | Confirming an email on the website's domain verifies a company whatever name it was given, at sign-up and again after an email change (also after a rename). Accepted: the badge says the poster controls that domain, and a rename or domain move by a verified company drops the badge until an admin approves it                                                                                                                                                                                                                                                                                          | Show the verified domain next to the badge and in the job JSON-LD, or have an admin approve the name before the first badge |
| Résumé access ends 7 days after a decision             | An employer can download an applicant's résumé while the application is open and for 7 days after it is hired, rejected or closed; then the api stops serving it and the purge job deletes the application's copy. Accepted: an employer who needs it longer downloads it in that window, and a student's file doesn't stay with every employer they ever applied to                                                                                                                                                                                                                                         | Let a hired student agree to share their résumé with that employer for longer                                               |
| Shared scorecards don't follow the résumé window       | A scorecard the student shared stays readable on a decided or closed application, until the student unshares or deletes it or the attempt expires (180 days). Accepted: the student chose to share it and controls it from their applications page                                                                                                                                                                                                                                                                                                                                                           | Apply the same window as résumés                                                                                            |
| Interview links come from a fixed list of services     | An invite link must be on Zoom, Google Meet, Microsoft Teams, Webex, Whereby, GoTo Meeting, Jitsi Meet or Amazon Chime, or on the company's own domain. Accepted: it stops invites that point at look-alike login pages, and a company on another tool can host the link on its own domain                                                                                                                                                                                                                                                                                                                   | Let an admin add services to the list without a release                                                                     |
| A suspension leaves applications open                  | Suspending a company hides its jobs and locks its users out of applicants, but the students' applications keep their status and nobody tells them. Accepted: suspensions are rare and may be lifted, and closing would email every applicant                                                                                                                                                                                                                                                                                                                                                                 | Close open applications on suspension with their own reason and tell the students once                                      |
| The GitHub Pages demo is a static export               | Pages serves files only, so the demo has no accounts, no applying, no employer tools, a scripted partner only, and a practice history that lasts as long as the browser tab. Accepted: it shows the product without running the api, coach and MongoDB                                                                                                                                                                                                                                                                                                                                                       | Deploy the full stack (docs/deploy.md); the demo build stays as the public preview                                          |
