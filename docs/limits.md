# Known limits (intentional for v1)

PitchPerfect is a portfolio project. Each limit below is on purpose, and each has a way forward.

| Limit                                       | Why                                                                                                                                                                                                                                                                  | Path forward                                                                                     |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Legal pages are templates                   | Binding legal text needs a lawyer                                                                                                                                                                                                                                    | Replace `/privacy` and `/terms` content before any real launch                                   |
| One employer user per company               | Teams need invites, roles, and ownership transfer                                                                                                                                                                                                                    | Add `companymembers` with roles and invite tokens                                                |
| Admin is a CLI, not a UI                    | Small operational surface                                                                                                                                                                                                                                            | Add an admin app behind SSO if moderation volume grows                                           |
| Voice depends on browser speech APIs        | No paid speech service in v1; Firefox has no speech recognition                                                                                                                                                                                                      | Add server-side STT/TTS behind the coach with streaming audio                                    |
| No dark mode                                | Keep one polished theme                                                                                                                                                                                                                                              | Add a dark token set; components already use tokens only                                         |
| English only                                | Content, prompts, and rubric are English                                                                                                                                                                                                                             | Localize lessons + prompts; add a `locale` to attempts                                           |
| US states only for student location         | Demo audience is US-based                                                                                                                                                                                                                                            | Replace with country + region                                                                    |
| No GDPR data export                         | Not launching in the EU                                                                                                                                                                                                                                              | Add `GET /api/me/export` (JSON + résumé)                                                         |
| The daily token budget can be overshot      | It is checked before a session starts; sessions already running finish their turns and scoring                                                                                                                                                                       | Reserve an estimated session cost when starting and refund unused tokens at the end              |
| Rate limits are counted in MongoDB          | Fine for demo traffic: the counters are shared by every api instance, at the cost of a database write per counted request (only `/api/health` counts in memory, per instance)                                                                                        | Move the counters to Redis. The api config already accepts `REDIS_URL`, but no limiter reads it  |
| No payments or subscriptions                | Out of scope                                                                                                                                                                                                                                                         | —                                                                                                |
| No messaging between employers and students | Email notifications cover interviews                                                                                                                                                                                                                                 | Add threaded messages with moderation                                                            |
| Users under 18 can't sign up                | Protects minors' data and avoids consent flows                                                                                                                                                                                                                       | School programs would need guardian/school consent flows                                         |
| Forgot-password is limited per email        | 3 requests an hour per address stops reset-email floods, so someone who knows an address can use the limit up and delay that user's own reset for the rest of the hour. Accepted: the spec mandates the per-email limit and the reset link is the only thing delayed | Add a second, per-IP limit and let a signed-in user change their password without the email flow |
| Sign-up attempts notify an existing address | Signing up with a registered email answers `201` like a new account and emails the real owner, so repeated attempts (up to the 3/hour/IP limit) send that person repeated notices. Accepted: the spec mandates the no-enumeration answer and the notice              | Rate-limit the notice per address (one an hour) independently of the sign-up limit               |
| The GitHub Pages demo is a static export    | Pages serves files only, so the demo has no accounts, no applying, no employer tools, a scripted partner only, and a practice history that lasts as long as the browser tab. Accepted: it shows the product without running the api, coach and MongoDB               | Deploy the full stack (docs/deploy.md); the demo build stays as the public preview               |
